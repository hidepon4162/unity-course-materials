## 生徒向け：使い方

1. 上記テンプレートを開く
2. 内容を **自分のリポジトリの `README.md`** にコピーする
3. 毎日「進捗メモ」を更新して commit / push する
4. リポジトリ作成後、**指導講師を Collaborator に追加**する
